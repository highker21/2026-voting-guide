# 2026 投票指南（直轄市長／縣市長、議員、村里長）

115 年（2026）地方公職人員選舉的投票參考。先選縣市、鄉鎮市區、村里，就能看到您這一票會投的所有選舉與登記參選人。

- 投票日：2026-11-28（六）
- 資料原則：只放官方資料（中選會與各選委會的登記名冊、選舉公報、議會紀錄、監察院政治獻金），每一項都附出處，不放生日、照片、媒體臆測。
- 目前階段：已審定、號次已抽定；縣市長與議員的學歷、經歷、政見依 115 年選舉公報（中選會，2026-11-16 取得）更新。村里長公報由各縣市選委會發行，尚未整理。

## 架構

設計參考 [g0v/2020voting-guide](https://github.com/g0v/2020voting-guide)，沿用它「爬蟲 → 資料 → 前端」的分層，但不使用 Go 後端與 App Engine，改成靜態 JSON 加 GitHub Pages。

```
crawler/   抓取與解析官方檔案（raw/ 存原始 PDF）
data/      index.json（縣市清單）、<code>.json（縣市長＋議員）、<code>/li-<鄉鎮市區>.json（村里長）
index.html 單檔前端
```

### 115 年選舉公報（學歷、經歷、政見）

來源：[中選會 選舉及公民投票公報](https://bulletin.cec.gov.tw/)，直轄市長 6、縣市長 16、議員 181 個 PDF（2026-11-16 下載，存在 repo 外）。公報內容由候選人自填、選委會編印。

| 步驟 | 腳本 | 說明 |
|---|---|---|
| 解析 | `crawler/parse_bulletin.py` | 以號次數字或名冊姓名當錨點，沿表格框線切出學歷／經歷／政見格，逐字依座標歸格（同一基線跨欄的字會被拆回各格）；出生年月日、性別、出生地不取 |
| 對應 | `crawler/match_bulletin.py` | 依縣市＋選舉＋姓名對回名冊；文字層姓名缺字或錯字時，限同選區＋同號次＋姓名部分相同才採用。號次與本站不一致者列出、不自動改（本次 0 筆） |
| 核對 | `crawler/ocr_check_bulletin.py` | 每一格轉影像再用 macOS Vision OCR 讀一次，與 PDF 文字層比對；相似度 < 0.85、OCR 字數明顯較多（漏行）、或含私用區字元者，該格不轉載，畫面改指向公報原檔 |
| 輸出 | `crawler/finalize_bulletin.py` → `crawler/bulletin_115.json` | build_data 讀取；政見以圖片刊登者標示「以圖片刊登」並附原檔連結 |
| 圖檔號次 | `crawler/ocr_numbers_bulletin.py` → `crawler/bulletin_115_ocrnum.json` | 整份是圖片的公報（南投縣、連江縣部分選區）整頁 OCR，只用來確認本站既有號次；一致者改以公報為出處 |

已知限制：南投縣全部、連江縣第二／三選區的公報是圖檔，學經歷與政見不轉文字，只附原檔連結。部分 PDF 字型對照表有誤（例如畫面「瑋」、文字層「璋」），由 OCR 核對擋下整格錯亂者，但單一錯字仍可能漏網，以公報原檔為準。

重建資料：先下載中選會名冊 PDF 到 `crawler/raw/cec_64709/`，執行 `parse_cec_list.py`，再執行 `python3 crawler/build_data.py`。

### 地址與定位
- 地址解析（縣市、鄉鎮市區、村里名稱）只在瀏覽器內進行，不送出。
- 「用目前位置判斷村里」：瀏覽器定位結果只在本機與 [內政部國土測繪中心 村里界圖（TWD97 經緯度，115/08/17）](https://data.gov.tw/dataset/7438) 比對（mapshaper 簡化 12%，`crawler/village_boundary/`），不送出位置。

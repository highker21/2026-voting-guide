# 2026 投票指南（直轄市長／縣市長、議員、村里長）

115 年（2026）地方公職人員選舉的投票參考。先選縣市、鄉鎮市區、村里，就能看到您這一票會投的所有選舉與登記參選人。

- 投票日：2026-11-28（六）
- 資料原則：只放官方資料（中選會與各選委會的登記名冊、選舉公報、議會紀錄、監察院政治獻金），每一項都附出處，不放生日、照片、媒體臆測。
- 目前階段：登記名冊（中選會 115/09/07 製表）。資格審定與號次抽籤後更新；選舉公報發布後（約 11 月中）補上學經歷與政見。

## 架構

設計參考 [g0v/2020voting-guide](https://github.com/g0v/2020voting-guide)，沿用它「爬蟲 → 資料 → 前端」的分層，但不使用 Go 後端與 App Engine，改成靜態 JSON 加 GitHub Pages。

```
crawler/   抓取與解析官方檔案（raw/ 存原始 PDF）
data/      index.json（縣市清單）、<code>.json（縣市長＋議員）、<code>/li-<鄉鎮市區>.json（村里長）
index.html 單檔前端
```

## 資料來源與處理

| 資料 | 來源 | 處理 |
|---|---|---|
| 登記參選名單（首長 81、議員 1,502、村里長 14,100） | [中選會 115年地方公職人員選舉候選人登記名冊](https://web.cec.gov.tw/central/article/64709)（115/09/07 製表） | `crawler/parse_cec_list.py`：`pdftotext -bbox` 依字的座標切欄，各縣市人數已與名冊逐一核對 |
| 議員選舉區範圍、名額 | 中選會 115/08/20 選舉公告（掃描檔，人工轉錄；席次合計 919 與中選會公布一致） | `crawler/district_map.json` |
| 村里清單 | 內政部戶政司 ODRP010（115/09） | `crawler/villages.py`；造字（PUA）以對照表換成標準字，CJK 相容字以 NFC 正規化 |
| 2022 當選（畫面標「2022 當選」） | 中選會選舉資料庫 votedata.zip | 首長比對同縣市、議員比對同縣市同選區、村里長比對同村里；同名但選區不同者標為「尚未比對」 |

名冊中因罕用字缺字的姓名（18 筆）不猜字，畫面顯示「請見官方名冊第 N 頁」。缺字的村里（6 筆）依名冊前後順序對照內政部村里清單補回。

重建資料：先下載中選會名冊 PDF 到 `crawler/raw/cec_64709/`，執行 `parse_cec_list.py`，再執行 `python3 crawler/build_data.py`。

### 地址與定位
- 地址解析（縣市、鄉鎮市區、村里名稱）只在瀏覽器內進行，不送出。
- 「用目前位置判斷村里」：瀏覽器定位結果只在本機與 [內政部國土測繪中心 村里界圖（TWD97 經緯度，115/08/17）](https://data.gov.tw/dataset/7438) 比對（mapshaper 簡化 12%，`crawler/village_boundary/`），不送出位置。

# 2026 投票指南（直轄市長／縣市長、議員、村里長）

115 年（2026）地方公職人員選舉的投票參考。先選縣市、鄉鎮市區、村里，就能看到您這一票會投的所有選舉與登記參選人。

- 投票日：2026-11-28（六）
- 資料原則：只放官方資料（中選會與各選委會的登記名冊、選舉公報、議會紀錄、監察院政治獻金），每一項都附出處，不放生日、照片、媒體臆測。
- 目前階段：登記名冊（中選會 115/09/07 製表）。資格審定與號次抽籤後更新；選舉公報發布後（約 11 月中）補上學經歷與政見。

## 架構

設計參考 [g0v/2020voting-guide](https://github.com/g0v/2020voting-guide)，沿用它「爬蟲 → 資料 → 前端」的分層，但不使用 Go 後端與 App Engine，改成靜態 JSON 加 GitHub Pages。

```
crawler/   抓取與解析官方檔案（raw/ 存原始 PDF）
data/      index.json（縣市清單）、<code>.json（縣市長＋議員）、<code>/li-<鄉鎮市區>.json（村里長）
index.html 單檔前端
```
